# App iPhone para Pedidos DM

La app de pedidos DM funciona como PWA. No necesita App Store ni TestFlight.

## Link

- https://bellymonsterbites.com/pedidos-dm

## Instalar en iPhone

1. Abre Safari en el iPhone.
2. Entra a https://bellymonsterbites.com/pedidos-dm
3. Toca **Compartir**.
4. Toca **Agregar a pantalla de inicio**.
5. Guarda el acceso como **Belly DM**.

## Actualizaciones

Cuando se actualice el sitio, el acceso de pantalla de inicio abre la version
nueva del mismo link. Si Safari conserva cache viejo, cierra la app desde el
selector de apps y vuelve a abrirla.

## Nota sobre IPA

Compilar una app iPhone nativa (`.ipa`) requiere macOS, Xcode, cuenta de Apple
Developer y firma. En Windows este repo puede compilar la web/PWA, pero no puede
generar un `.ipa` instalable.
